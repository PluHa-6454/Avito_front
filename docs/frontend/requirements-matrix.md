## Нефункциональные требования

| Требование | Как выполняем на фронте | Этап | Проверка |
|------------|--------------------------|------|----------|
| Локальные операции < 1 с | optimistic UI, кэш Query, скелетоны | 5–9 | замер E2E, профилирование |
| LLM не блокирует интерфейс | StreamManager, батчинг токенов, навигация | 5 | E2E во время стрима |
| Корректная обработка сбоев | единый маппинг ошибок, retry, таймауты | 9 | тесты ошибок |
| Покрытие строк > 80% | Vitest + RTL + MSW, порог в конфиге | 10 | `npm run test:coverage` |
| Запуск по инструкции | Docker + mock-api, README | 11 | чистый клон, `docker compose up` |
| Воспроизводимость | фикстуры и mock-сценарии в репозитории | 2 | E2E без сети |
| Наблюдаемость | request_id в ошибках, консольные логи без ПДн | 9 | код-ревью |
| Безопасность | confirm-only запись, нет raw HTML, токен в sessionStorage (прототип) | 4–6 | тесты, ревью |
| Совместимость со стеком Авито | React, TypeScript, TanStack, Zustand, Zod, Docker | все | код-ревью |
| Локализация | русский UI и ошибки | все | UI-тесты |
| Приватность | только синтетические данные | все | ревью данных |
| Поддерживаемость | слои, контракт, документация | все | код-ревью |

## Критерии приёмки сценариев (приложение B ТЗ)

- [x] SDD-спецификация (для бэкенда) написана до кода — вне фронта, но контракт зафиксирован.
- [x] Основной поток проходит вручную от запроса до результата (и покрыт E2E).
- [x] Альтернативы и ошибки обработаны понятным текстом.
- [x] Права проверяются; запрещённое действие отклоняется (403/422 в UI).
- [x] Запись выполняется только после подтверждения.
- [x] Повторное подтверждение не создаёт дубль.
- [x] Результат сохранён и виден в истории и `/requests`.
- [x] Шаг онбординга закрывается автоматически.
- [x] Есть тесты, покрытие не снижает общий порог.
- [x] Сценарий включён флагом и упомянут в README/презентации.
