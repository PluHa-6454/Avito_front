# Design notes AI-buddy

Статус: **этап 3**. Источники: ТЗ §7 (UI/UX), публичные материалы о дизайн-системе Авито,
собственные решения. Это не копирование фирменного стиля, а перенос принципов: ясность,
предсказуемость, модульность, доступность.

## Принципы

1. **Одна задача — один акцент.** На экране не больше одной основной кнопки; вторичные действия
   вынесены в outline/ghost.
2. **Состояние всегда видно.** Загрузка, пусто, ошибка, нет прав, стрим и результат — отдельные
   визуальные состояния, а не пустой экран.
3. **Контраст и фокус — часть компонента.** Все интерактивные элементы имеют видимое фокусное
   кольцо и работают с клавиатуры.
4. **Синтетические данные заметны.** Источники и документы помечаются бейджем «тестовый».
5. **Спокойная эстетика.** Нейтральные поверхности, синий акцент, мягкие радиусы, без тяжёлых
   теней и градиентов.

## Токены

Файл: `src/index.css`. Светлая тема — основная; тёмная зарезервирована.

### Цвет

| Токен | Назначение |
|-------|------------|
| `--background` / `--foreground` | фон приложения и основной текст |
| `--card` / `--card-foreground` | карточки, панели |
| `--muted` / `--muted-foreground` | вторичные поверхности и текст |
| `--primary` / `--primary-foreground` | основное действие, активная навигация |
| `--accent` / `--accent-foreground` | мягкий акцент, выбранный пункт |
| `--destructive` | ошибки и опасные действия |
| `--success` / `--warning` / `--info` | статусы: готово, ожидает, в работе |
| `--border` / `--input` / `--ring` | границы, поля ввода, фокус |

Проверка контраста: `npm run check:contrast` (WCAG AA, oklch → sRGB → luminance).
Текущий результат: все текстовые пары ≥ 4.5:1, `--input` и `--ring` ≥ 3:1, `--primary` ≥ 3:1.

### Типографика

- Семейство: Inter / system-ui, fallback `Segoe UI`, Roboto.
- Шкала: 12 px — подписи и бейджи; 14 px — основной текст; 16 px — ввод; 20–24 px — заголовки.
- Межстрочный интервал: 1.4–1.6; заголовки — 1.2.
- Числа и идентификаторы — `font-mono` (request_id, номера заявок).

### Отступы и радиусы

- Базовая сетка 4 px: 4 / 8 / 12 / 16 / 24 / 32.
- Радиусы: 8 px — бейджи и мелкие элементы, 12 px — карточки и поля, 16 px — крупные панели.
- Контейнер: максимум 1440 px, боковые отступы 16 px на узких экранах и 24 px на десктопе.

### Тени

Мягкая тень только у «плавающих» слоёв (dropdown, sheet, toast). Карточки отделяются
границей и фоном, а не тенью.

### Фокус

- `focus-visible` — кольцо 3 px цветом `--ring/50` + смена границы на `--ring`.
- Для ссылок и кнопок — обязательный `outline-none` только вместе с ring.
- Skip-link «Перейти к содержимому» — первый элемент в DOM.

### Motion

- 150–200 ms, `ease-out`; без бесконечных анимаций.
- `prefers-reduced-motion: reduce` отключает transition/animation.

## Состояния компонентов

| Состояние | Как выглядит |
|-----------|--------------|
| default | фон/граница по токенам, читаемый текст |
| hover | `--muted` или `--primary/80`, без скачков размера |
| active | лёгкий сдвиг на 1 px только у кнопок |
| focus-visible | ring 3 px, виден на любом фоне |
| disabled | opacity 50%, `pointer-events: none` |
| loading | skeleton или spinner + `aria-busy` |
| error | `ErrorState`: текст, hint, request_id, «Повторить» |
| no access | `NoAccessState`: замок, объяснение, кому обратиться |

## Компоненты этапа 3

- `AppShell` — шапка, навигация, skip-link, футер.
- `PageHeader` — заголовок страницы и действия.
- `EmptyState` — пустое состояние.
- `LoadingState` — skeleton-заглушка.
- `ErrorState` — ошибка с retry и request_id.
- `NoAccessState` — нет прав.
- `SyntheticBadge` — метка «тестовый».
- `RoleChip` — роль и команда.
- `StatusBadge` — статусы действий и шагов.
- shadcn/ui: Button, Card, Input, Textarea, Badge, Tabs, Dialog, Sheet, Tooltip, Skeleton,
  Alert, Avatar, ScrollArea, Separator, DropdownMenu, Sonner.

## Адаптивность

- 1440 px — максимальная ширина контента.
- 1280 px — целевой десктоп: чат и панель онбординга рядом.
- 1024 px — панель уходит под чат, навигация остаётся горизонтальной.
- Меньше 1024 px — прототип не оптимизирован, но не ломается.

## Проверки

- `npm run check:contrast` — контраст токенов.
- Playwright smoke на 1440×900; визуальная проверка 1280/1024 — этап 9.
- Клавиатурная навигация: skip-link, nav, кнопки, поля; фокус не теряется.
- Все данные синтетические; реальные ПДн не используются.
